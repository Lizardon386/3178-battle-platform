# @3178/sdk-tools

3178 SDK 的构建与打包工具：

- `bpmap` CLI：`pack` / `inspect` / `unpack` / `doctor`
- `templates/scripts/setup-sdk.mjs`：把 SDK tarball 安装到游戏工程
- `templates/scripts/build.mjs`：构建服务端/客户端、生成清单、打包并校验

```bash
npx bpmap --help
```
