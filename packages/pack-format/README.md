# @lizardon386/pack-format

3178 单文件游戏包 `.bpmap` 的读写库：包头、文件清单、SHA-256 校验、打包和解包缓存。

这是 Node.js 库；游戏运行时通常通过 `@lizardon386/game-sdk/node` 使用，构建/打包则由 `@lizardon386/sdk-tools` 的 `bpmap` CLI 调用。
